# 测试覆盖

ANote 的检查分为单元测试、浏览器回归、服务端集成和桌面回归。测试数据使用合成内容，输出保存在 Git 忽略目录中。

| 范围 | 主要内容 |
| --- | --- |
| 文档与同步 | 富文本保真、Markdown 往返、三方合并、冲突与评论锚点 |
| MCP | 文档模型、权限、OAuth、编辑预览、评论和附件 |
| 网页 | 导航、编辑器、共享、团队管理与主题 |
| 服务端 | 数据持久化、权限、上传、历史和回收站 |
| 桌面 | 个人离线模式、保存重启、目录隔离与团队同步 |
| 国际化 | 语言识别、占位符、英文文案完整性与切换前保存 |

构建或打包成功只能说明对应环节通过，不代表其他平台已完成运行验证。Windows 与 macOS 的原生运行、系统密钥库、签名和公证需要在相应系统检查。

检查命令与测试环境配置见[开发指南](development.md)。当前修改的检查结果应以对应提交或发布记录为准，本文不作为某一版本的通过证明。
