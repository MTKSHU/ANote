03 / 连接 AI 工具

MCP · 本地与服务器

本地笔记，也能连接 AI。

个人 App 可开启本地 MCP，让 AI 检索、阅读和编辑当前笔记目录，无需另建笔记服务器。团队服务器支持 OAuth 或独立令牌连接远程 MCP，访问范围仍由账号已有权限决定。

05 / 选择使用方式

先为自己记录，再按需连接团队。

桌面客户端本身就是完整的个人笔记 App。个人使用从下载开始；团队需要集中管理和多人协作时，再部署服务器。

▤

个人 App · 无需服务器

下载、选目录，开始记录。

本地知识库、富文本、附件、历史和 Markdown 都在自己的电脑上使用；本地 MCP 还可让 AI 连接当前目录。无需账号，也无需 Docker 或服务器。

  1. 下载 Windows、macOS 或 Linux 桌面客户端。
  2. 打开后选择“本地个人笔记”。
  3. 选择存储目录，直接开始写作。
下载个人 App↗
⌘

团队平台 · 自托管

在团队的服务器上，一起积累。

管理员部署平台，成员通过浏览器或桌面客户端连接。多人协同、评论、权限管理与只读分享集中在同一空间，普通成员无需各自部署。

  1. 管理员使用 Docker 部署 ANote。
  2. 成员打开平台地址，或在桌面端填写该地址。
  3. 登录后按权限使用个人与团队知识库。
查看团队部署指南↗

服务器笔记，也可按需留一份在本机。

服务器模式可选择保留有权读取的笔记与附件，断网后继续使用，重连后同步。独立备份采用分块增量保存，复用未变化内容，并支持查看、恢复和删除时间点。本地个人笔记始终保存在自己的目录，连接团队不会自动上传。

需要更换工作目录时，可校验并迁移笔记与附件，保留原目录副本供确认。
