02 / 一起沉淀知识

让讨论，留在内容旁边。

把项目资料、会议纪要和操作指南放在同一个地方。多人实时编辑，围绕段落讨论，也能通过历史版本回看内容如何变化。

◇

个人内容，默认私有

自己的记录，按需要分享给指定的人。

▥

团队资料，集中整理

成员按权限查阅，编辑他人的内容需要授权。

↗

对外展示，控制范围

外部链接只读且可撤销，评论和历史不对外公开。

03 / 连接 AI 工具

MCP / OAuth

让 AI 从已有的知识出发。

04 / 看见与整理

有些差异，放在一起就明白。

拖动分界线，对比两张图片。编辑前后、设计方案或实验结果，都能和说明一起留在笔记里。

也可以，把思路展开。

用思维导图连接主题与分支。在 ANote 中可以编辑节点、增加分支、调整位置和缩放画布。

05 / 选择使用方式

一个人记录，一群人积累。

▤

本地个人模式

保存在自己手边。

无需账号或服务器，选择一个自己的目录，保存正文、附件和历史。以后连接团队，也不会自动上传这些个人笔记。

离线可用 · 自选目录 · 个人笔记
⌘

自托管团队模式

放在团队自己的空间。

将 ANote 运行在自己的服务器上，通过网页或桌面协作。桌面端提供离线缓存和受管 Markdown 同步，并按账号和服务隔离数据。

网页与桌面 · 多人协作 · Markdown 同步

Markdown 同步保留结构化内容，无法自动合并的变化会提示冲突。重要数据仍需要独立备份。
