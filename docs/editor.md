# ANote 编辑器

正文通过空行开头的 `/` 菜单插入标题、列表、引用、代码、表格、媒体及增强内容；表格单元格分别处理。选中文字显示格式浮动工具，可设置字重、斜体、字号、文字／背景颜色与对齐。段落格式也可视化切换，文内目录按标题层级缩进。

代码块支持语言和高亮，Mermaid 从代码语言选项进入。Mermaid 与思维导图支持画布缩放和拖动；思维导图节点可双击或按空格编辑，通过 Tab／Enter 增加分支。LaTeX 支持行内及独立公式，待办在有编辑权限时可在阅读模式勾选。

## Markdown

支持常用 Markdown 快捷输入与纯文本粘贴，包括标题、列表、引用、代码和链接。本地双向同步使用受管目录和同步基准；复杂表格、导图、双图对比及媒体排版仍由结构化模型保存。

## 媒体与附件

在正文上传、粘贴或拖入文件，无需先去独立素材区。图片／视频支持等比尺寸调整、对齐，双击进入查看；图片查看支持放大缩小和拖动，视频使用原生播放控制。双图对比通过直接拖动分界线比较两张图片，透明图像分别裁切；更多图片可用表格组织。

Office 和原生三维工程按原件保存与下载。浏览器内三维预览面向支持的导出格式，Gaussian PLY 需要 `binary_little_endian`；预览能力不代表具备原生 Blender／Unity／UE 渲染或在线 Office 编辑。

## 评论与历史

可从当前段落或选区添加评论，在线程中回复、解决或重开，通过原文标记定位。评论和历史版本分别打开独立侧栏；正文持续保存，有变化时按分钟间隔保留历史，支持命名版本和恢复。Ctrl／Command+S 触发笔记保存。

## 笔记位置

知识库中可拖拽目录和笔记，调整顺序与层级。笔记设置也保留知识库与目录选择；跨库提交先在同一窗口确认目标和授权变化，仅支持本人个人库互移或同一团队内互移。

## 共享与回收站

内部链接按登录账号权限访问。外部链接为可撤销只读链接，支持限时或永久有效，附件跟随笔记权限，评论与历史不公开。团队外链同时受团队安全策略控制。

笔记、知识库与团队删除后可在回收站按类型恢复或彻底删除，满 30 天后自动清理。删除目录会把内容移至上一级。回收站、版本历史与同步不代替独立备份。
