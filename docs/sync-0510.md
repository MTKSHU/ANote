# 0.5.10 源码同步与验收

将开发工作树的 0.5.10 应用、共享包、测试、图标、性能补丁和移动源工程同步至公开版。保留 Apache-2.0 许可证、公开仓库元数据、GitHub Pages、ANote 技术命名及简体中文／英文支持；补充 787 条英文文案。旧版公开仓库的 25 个 SQL 迁移文件保持原字节，新增默认名称迁移不覆盖部署者配置的站点名称。

本记录对应提交和推送前的本地源码同步与验收，未导入开发仓库的 Git 历史，也未部署在线服务；后续 Git 提交和推送由维护者单独执行。维护者的真实环境文件、身份服务密钥、账号令牌、数据库与备份、安装包、私有发布记录及临时目录均不纳入同步。默认服务器与 OIDC 地址为空，由部署者配置；测试地址使用示例域名或独立 Docker 网络。

文档中的维护者示例分享地址已从当前文件删除。目标仓库原有提交历史仍保留原内容，本次不改写历史；公开分享链接应按实际保密要求单独管理。

## 验收

- `npm ci`、网页／API／共享包编译和桌面编译通过；516 个 JavaScript／TypeScript 文件的语法、JSON、工作区依赖元数据及 Markdown 相对链接检查通过。
- 325 个单元、存储、迁移、协作编码及权限用例分批验证通过。旧测试中硬编码的 schema、迁移新增元数据断言、API 模块初始化顺序及隔离存储环境已校正，失败项定向复测通过。
- 32 个网页用例通过，覆盖桌面与手机视口、表格文字选择／列宽／垂直对齐、首行缩进、PDF、知识库归档及 MCP。手机项目另有 2 个重复协议／物理鼠标用例按设计跳过，已由桌面项目验证。
- 4 个 Linux Electron 用例通过，覆盖语言切换保存未完成输入、本地 MCP、表格与实际 PDF。
- Android 编译、7 项单测与 lint 通过；HarmonyOS 未签名 HAP 编译及字节码校验通过；iOS 源工程归档通过。移动界面版本取自应用元数据。
- 待同步文件采用 Gitleaks 8.30.1 默认规则扫描，结果为 0 项密钥发现；另检查私有域名、主机路径、原技术命名、环境文件及签名资料。自动扫描中的缓存索引表达式误报已人工确认并通过等价排版消除。

日志及机器报告保存在忽略的 `artifacts/sync-0510/`。测试使用独立网络、数据库及附件卷；不使用在线笔记。Docker 构建与运行任务串行限制为最多 2 CPU，构建内存不超过 2300 MiB。

## 验收范围

桌面执行环境为 Linux Electron；网页手机覆盖为 Chromium 手机视口。未在 macOS、Windows 或移动实机验收。Android 使用独立测试签名，HarmonyOS 包尚需开发者签名，iOS 未编译 IPA。公开发布安装包仍需分发者完成对应平台的签名和设备验收。
