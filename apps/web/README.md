# ANote 网页

React／TypeScript 网页，通过个人和团队知识库组织笔记。共享编辑器位于 packages/editor，支持富文本、表格、媒体、代码、公式、思维导图与双图对比；评论、版本、共享和权限由 API 提供。

侧栏提供导航与知识库入口，笔记页面保留同库笔记列表及文内目录。界面支持简体中文、英文和 Light／Dark／Auto 外观；用户可修改昵称，管理员可配置站点名称、公共地址与认证方式。

使用见[编辑器指南](../../docs/editor.md)，部署见[部署指南](../../deploy/README.md)，Docker 浏览器回归见[开发指南](../../docs/development.md)。
