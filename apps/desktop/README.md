# ANote 桌面客户端

Electron 复用 React 编辑器与同步内核。启动页提供无需账号的本地个人模式，以及连接自部署团队空间的模式。当前预览版为 0.5.0，应用、程序及发行包名称统一为 ANote。

个人模式数据保存在用户选择目录的 .anote，团队连接按服务器和账号隔离离线缓存、受管 Markdown 目录及同步队列。两个模式不会自动互传数据。

功能、构建、同步限制与系统验收见[桌面指南](../../docs/desktop.md)；程序与配置标识见[命名约定](../../docs/naming.md)。依赖、编译和 Electron 测试均在 Docker 中执行，见[开发指南](../../docs/development.md)。
